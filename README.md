# STELLA HOSTIS

This is my first game made with Unity and my first time using GitHub.

The game is heavily inspired by Galaga, but I'm experimenting with new mechanics and combining 2D and 3D elements to make it feel like its own experience.

It's also a remake of a game I built on Scratch when I was 14. Looking back, it's pretty rough and only has four levels, but rebuilding it with modern tools has been a fun way to learn game development.

Check out the original here:
https://scratch.mit.edu/projects/191331213/
